name: Email browser draft visibility
description: Preserve legacy local drafts while hiding copies already registered on the server.
---

Hide legacy browser drafts that have the same workspace and placeholder name in the shared registry; hide the browser-draft section when no unimported drafts remain in the selected workspace. Do not delete the local copies.

**Why:** The user approved hiding the duplicate browser-draft section without deleting earlier draft work or affecting active email placeholders.

**How to apply:** Treat this as display filtering only. Preserve stored drafts, server definitions, activation and email delivery; keep unimported drafts recoverable and storage failures explicit.
