name: Lessons PDF template policy
description: Official revised Word form governs the appearance of downloaded and emailed Lessons PDFs.
---

Use the user's revised official Lesson Learned Word form as the visual authority for both PDF downloads and email attachments, not the older exported PDF.

**Why:** The user explicitly required the revised Word document's logo, title, colour scheme and layout; the older PDF used superseded SHEQ branding and document-control details.

**How to apply:** Preserve the supplied template rather than approximating it with a newly drawn layout. Populate real record values, photos and actual signatures only; never copy example content or invent signatures.

The form's table rows must automatically expand to show their full contents at a readable size. If a row exceeds a page, continue that same table row across pages with its label repeated. Preserve the original branding, labels, evidence, approval fields, outer frame and document controls.

**Why:** The user reported truncated narrative and title fields and explicitly requested content-driven table alignment. A shortened main cell with a separate full-text appendix is not an adequate substitute for full content in the table.

**How to apply:** Apply this policy to the shared download/email PDF renderer. Do not reintroduce ellipses, fixed-height clipping, whole-form shrinking, or “See continuation” replacements for field values.

The Description, Reference, Root Cause, Correction and Corrective Action value cells use Word-style justified paragraphs: wrapped lines meet both margins, while each paragraph's final line stays flush left.

**Why:** The user explicitly requested Justify alignment for this table section, replacing centered narrative text.

**How to apply:** Preserve paragraph breaks and blank lines, including through page splits. Do not apply this narrative alignment rule to metadata or signature cells.
