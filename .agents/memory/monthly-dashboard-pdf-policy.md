---
name: Monthly dashboard PDF policy
description: Supplied presentation and spreadsheet govern the separate monthly dashboard export, not existing monthly report PDFs.
---

The Monthly Dashboard PDF is a separate five-page presentation-style export. The customer's supplied presentation governs its cards, charts, colors and page layout; the accompanying spreadsheet governs its mappings. Preserve the existing Word-layout Monthly Report PDF, Excel exports, data-entry fields and calculations.

**Why:** The user requested two distinct download buttons, not replacement of the existing monthly report or a new dashboard application.

**How to apply:** Saved QMS360 calculations override illustrative formulas and numbers in the reference. Ageing charts use the actual input bands, never fabricated subdivisions. Missing values remain explicit and template examples must never reach a real export.

The new dashboard's portfolio annotation follows the mapping workbook's form-style completeness rule: show Pending with reported/active coverage until all authorized active projects have valid submitted/approved reports for that month. This differs intentionally from the existing Monthly Report PDF's available-report download-time average.

**Why:** The new workbook explicitly maps the dashboard to the form's portfolio coverage display. Earlier requirements for the separate Monthly Report PDF explicitly allowed an average before all active projects reported.

**How to apply:** Keep both policies independent and preserve tenant, project and full-versus-own visibility when calculating either aggregate. Do not replace one export's policy globally to make them identical.
