---
name: QA/QC PDF template policy
description: User-approved exact-PDF mapping approach and versioning scope.
---

Use uploaded PDFs as exact backgrounds with admin-confirmed field mappings, rather than inferring or recreating their design with AI. Keep multiple named versions. Users select published templates for PDF downloads; the existing data-entry fields and calculations remain authoritative.

**Why:** The user explicitly chose “Exact PDF layout with field mapping” after asking for admin uploads, multiple names/versions and user-selectable PDF forms. A reference PDF alone cannot reliably identify the underlying QA/QC business fields.

**How to apply:** Keep template changes in QA/QC only. Require preview and approval before publishing. Preserve complete report data, calculations, historical baselines, filters and snapshot/movement semantics even when a layout maps only selected values; do not let template uploads redefine the business schema.
