QMS360 schema mismatch

Live development and production PostgreSQL catalog comparison. No schema or data was changed to produce this report. This is an inventory for review, not a production migration script.

Production symptom: Audit administration requests GET /api/audit/admin/roles and GET /api/audit/admin/users return HTTP 500. The deployed code reads app3_audit.workspace_roles.role_authorization_level, which exists in development but is absent in production. The problem is not specific to one user's role.
Support attention: A development-to-production schema comparison in the Publishing tool reported no pending statements during investigation, despite the live catalogs differing as documented below. Please reconcile schema only, preserve existing production data, and do not use an overwrite-data option. Adding the Audit role column alone is not a promise of zero data changes: the running application has a legacy backfill that may set approval levels for existing L1, L2, and L3 roles.

Scope and findings

Compared PostgreSQL objects in public, shared, app1_qaqc, app2_lessons, and app3_audit. The catalog comparison covered tables/views, columns and defaults, table constraints, indexes, enum labels, sequences, non-internal triggers, row-level policies, routines, domains, and extensions in those schemas. It did not compare table rows, privileges, ownership, or objects in the drizzle bookkeeping schema.

Recommended support checks

  1. Confirm that the published API and the read-only production catalog refer to the same managed production database.
  2. Investigate why the Publish schema comparison reports no changes when these live objects differ. Reconcile schema without replacing production row data.
  3. Account for the application's legacy Audit approval-level backfill: L1 Approver, L2 Approval Role, and L3 Approver currently match its criteria.
  4. After reconciliation, verify the missing objects in the production catalog and check that Audit Roles & Permissions and Users & Access return successful responses.
